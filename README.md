# Extended-analysis-for-infer-subc-v2.0.0b1
This repository contains extended codes for:
- hierarchical clustering analysis [biclustering_firstpass_v7; timecourse_clustering_firstpass_soma_v1]
- dynamic time warping (DTW) [Tethers_Contacts_DTW_v3.1]
- extended organelle contacts analysis [contact_analysis_suite_v2; k-way_with_cell_fraction_v2]

These codes are based on infer-subc-v2.0.0b1 imaging data ouputs, and were used to generate data in the following preprint [doi: https://doi.org/10.64898/2026.02.10.704675]
